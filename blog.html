ksat: SAT solvers for Kotlin Multiplatform

November 2026

ksat ports four SAT solvers (microSAT, MiniSat, CaDiCaL and kissat) to plain Kotlin. There is no native library underneath, so they run on every Kotlin Multiplatform target: JVM, Android, iOS, native and the browser. The repo comes with examples for Android and iOS. To try it out, paste a formula in DIMACS format into the playground and solve it right in the browser.

ksat-chess: retro chess puzzles with SAT

November 2026

My goal with ksat was to crack retrograde chess puzzles with a SAT solver: given a position, which moves led there? ksat-chess does that and now has a nice web interface. Set up a position, and the solver finds every legal way the game can have reached it.

ktoy: see how a CPU works

September 2026

ktoy is an educational project about CPU architecture. It is built around the Toy CPU, a minimal 8-bit processor with 256 bytes of memory and a single accumulator. You write a program in C or assembly, compile and assemble it, and step through it one instruction at a time while the memory changes in front of you. It runs in the browser, on the desktop, on Android and on iOS.

On my YouTube channel ByteFred there are tutorials on ktoy and on how such a CPU is built.
