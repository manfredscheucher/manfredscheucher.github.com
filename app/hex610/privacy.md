# hex610-privacy

Public GitHub Pages host for the **hex610** privacy policy (Google Play requires a
public, non-PDF, non-editable HTTPS URL).

- Live URL (after Pages is enabled): **https://manfredscheucher.github.io/hex610-privacy/**
- Page content: [`index.html`](index.html)
- Master copy lives in the app repo at `hex610/_private/store-assets/privacy.html`
  — edit there, then copy over `index.html` here to keep them in sync.

## Enable GitHub Pages (one-time)

1. Create a **public** repo `hex610-privacy` under the `manfredscheucher` account and push
   this folder to it (Manfred does the create + push).
2. On GitHub: **Settings → Pages → Build and deployment → Source = "Deploy from a branch"**,
   Branch = `main`, folder = `/ (root)`, Save.
3. Wait ~1 min, then open https://manfredscheucher.github.io/hex610-privacy/ to confirm it
   loads.
4. Paste that URL into **Play Console → App content → Privacy policy**.
